# POS y cajas
Una caja abierta por usuario y comercio, asociada a una sucursal. Ventas por lote físico, búsqueda por código y precios recalculados en servidor; promociones porcentuales por producto/lote y proximidad a vencimiento.
Ingresos y retiros de efectivo independientes de finanzas; registrar el gasto/pago correspondiente por separado. El arqueo incluye fondo inicial, ventas vigentes y movimientos. Un retiro no puede superar el efectivo esperado.
Anulación completa solo por OWNER/MANAGER, mismo día argentino, caja original abierta. Reintegro manual confirmado por operador, no integrado con bancos. Se registra reversión, no se borra venta. Mercadería se descarta o regresa a lote completo bloqueado para revisión; jamás vuelve automáticamente a estar disponible. Ventas anuladas excluidas de resultado del período original (mismo día), descarte computado como merma. Pendientes: devoluciones parciales, devoluciones posteriores, pagos mixtos, múltiples cajas físicas por usuario, ARCA y hardware.
Comprobante interno imprimible no fiscal.
